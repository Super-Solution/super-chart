01拖動與縮放

在 K 線區左右拖曳、滾輪縮放，再移動十字線。先用基礎指標，感受圖表跟手程度。

02加大更新量

選 50,000 根與多指標，再開每秒 50 次更新。拖曳舊資料後按「回到最新」，觀察更新與互動是否順暢。

03畫線與編輯

新版選「trend line」後按住拖曳放置；舊版用左側工具列。再試選取、移動和復原，兩版畫線各自獨立。

04回放與完整介面

按「兩版回放」從末端前 180 根開始。回放後可用各版原生按鈕操作；切成單版看完整工具列。兩版原本都支援回放。

這次比較的是什麼？有哪些限制？

新版使用本輪優化後的本機 0.1.0 原始碼（改前基準 commit 5b9b7d0）；舊版使用已發布的 @super-solution/super-chart 0.0.53 與 KLineCharts 9.8.12。這是真正的兩代引擎，不是用同一張圖換皮。新版已把 Pro 封裝與底層繪圖換成自研實作，並使用新版公開 API；這個頁面沒有修改兩版套件。

兩邊使用同一固定公式、時間、資料筆數與更新序號。初始皆為約 160 根可見 K 線、MA(20) 與 VOL；多指標加入 EMA(21)、BOLL(20,2)、RSI(14)。指標初始化與計算慣例可能不同，不能把名稱與參數相同當作結果完全一致。圖內商品／週期可各自操作；上方會提示是否仍為同一行情。

並排會共享瀏覽器的 CPU/GPU 資源，適合操作體驗，不能據此宣稱正式的加速倍數。更新頻率是目標排程頻率，不是 FPS。回放由兩版自己的時鐘驅動，進度可能略有不同；另有單實例手動量測頁；本頁不會執行自動化測試。所有價格均為合成資料，不連交易所、錢包或帳戶。這是 Web 體驗，不是 React Native 原生渲染預覽。
