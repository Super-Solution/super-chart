Super Chart 單實例量測

選一個版本，頁面載入後按「開始量測」。每次依序平移、縮放、以 50 Hz 為目標送入 4 秒即時更新；結果會直接顯示在圖表下方。

比較時保持相同視窗尺寸、裝置與可見狀態。這裡使用獨立頁面，避免 iframe 背景節流；請勿同時執行兩組量測。

公開 API 驅動的 pan/zoom 是繪製負載，沒有模擬手指。rAF 間隔包含顯示器／瀏覽器排程，不是純 CPU 成本。loadMs 為 navigation 到 ready 後兩幀的代理值；舊版指標背景完成時點可能不同。heap 是未強制 GC 的瀏覽器估計值，不能當作單一圖表 retained heap。Canvas bytes 為 width×height×4 估算，不含瀏覽器／GPU 的額外配置。這是手動量測工具，不會執行 CI 或新增測試。
