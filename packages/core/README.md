# @supersolutions/super-chart-core

Renderer-free chart core: market-data contracts and loader, series and TA, indicators,
drawings, frame and workspace models, bar replay, analysis detectors and the React
Native lifecycle. No DOM; runs in Node, workers and React Native.

Entries: `.` (everything renderer-free), `/native` (adds the RN lifecycle adapters),
`/indicators` (15 technical and 19 classic definitions).
