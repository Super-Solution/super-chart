# @supersolutions/super-chart-web

Canvas chart engine and workspace for the browser: `SuperChart` / `ChartWorkspace`,
`EngineChart`, 65 drawing tools, replay, validated workspace JSON.

Entries: `.`, `/annotations` (symbol-scoped level, zone and marker layers), `/overlays`
(volume profile, fair-value gaps, order blocks). Give the host element an explicit height.
