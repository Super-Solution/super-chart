# @supersolutions/super-chart-chat-plugin

super-chat plugin: shows a `super-chart.chart` card and gives an agent seven tools to
read and mark the chart. Depends on the Apache-2.0 `@supersolutions/super-protocol`.
See [docs/CHAT-PLUGIN.md](https://github.com/Super-Solution/super-chart/blob/main/docs/CHAT-PLUGIN.md).
